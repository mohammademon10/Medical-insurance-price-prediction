# 🏥 Medical Insurance Price Prediction

A machine learning-based web application that predicts medical insurance costs based on user health and demographic data.

---

## 🚀 Live Demo 🌐

👉 [https://huggingface.co/spaces/EmonHossain/Medical-insurance-price-prediction](https://huggingface.co/spaces/EmonHossain/Medical-insurance-price-prediction)

---

## 📌 Features ✨

* 🔮 Instant insurance cost prediction
* 🧑‍💻 Clean and user-friendly UI using Gradio
* 📊 Built on real-world dataset
* 🔁 End-to-end ML pipeline (Data → Preprocessing → Model → Deployment)

---

## 🧠 Machine Learning Model 🤖

* **Algorithm:** 📈 Regression (Scikit-learn / XGBoost)
* **Preprocessing:**

  * ⚖️ StandardScaler (for numerical features)
  * 🔠 OneHotEncoder (for categorical features)
* **Pipeline:** 🔄 Ensures consistent and clean transformation

## ⚙️ Installation (Local Setup) 🛠️

### 1️⃣ Clone the repository 📥

```bash
git clone https://github.com/mohammademon10/Medical-insurance-price-prediction.git
cd Medical-insurance-price-prediction
```

### 2️⃣ Install dependencies 📦

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the application ▶️

```bash
python app.py
```
